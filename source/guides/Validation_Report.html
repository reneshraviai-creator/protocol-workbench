Installer self-test

The offline Windows installer invokes the bundled self-test on the target PC before launching. The same check is available in Settings. It uses new temporary loopback servers, never saved project endpoints. This provides a target-machine check for the bundled runtime and protocol operations without connecting to your PLC.

Verification still required on Windows

  • Execute native Windows x64 binaries and Install.cmd on a Windows 10/11 PC.
  • Confirm desktop/Start-menu shortcuts, default browser launch, close/reopen behavior, startup at Windows login, and uninstall.
  • Validate network/firewall policy, certificates/account rights, and throughput against your actual PLC/diode/Modbus devices.
  • Windows background operation is per-user, not a pre-login Windows Service.

Known limits

This is a functional local app, not a bug-free guarantee or signed/certified industrial product. Protocol support is OPC UA and Modbus TCP. Modbus RTU/serial and other protocol drivers are not implemented. OPC UA gateway/scanner acquisition is polling, not subscriptions. The local UI is browser-based and bound to loopback. Multi-request writes are not atomic; disconnects may leave partial destination updates. The 2-second interval is measured and may overrun on slower equipment. Private project credentials are stored in local files, not an encrypted credential vault.
